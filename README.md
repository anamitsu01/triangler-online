# トライアングラー

点と点を線で結び、自分の電源の＋と−をつないで回路を通電させる2人対戦パズル。回路の中の三角形1つにつき1点、得点した三角形は盤面から消える。

## 動かし方

```bash
npm install
npm run dev        # http://localhost:3000
```

ホームの「CPUと対戦」(または部屋コード `ZZZZZ`)で、CPUを相手に1人で遊べます。

```bash
npm run simulate   # ルールの確認 + CPU同士で点20/30/40を200局ずつ対戦して統計を表示
npm run build && npm start
```

## ルールの実装

- 盤面・線の判定・通電はすべて `lib/board.ts`(サーバーとクライアントで共有)。
  - 通電する線 = ＋から−への単純経路に含まれる線。＋−を結ぶ仮想の辺を足したグラフで、その辺と同じ二重連結成分に入る線として求める。
  - 得点 = 3辺とも通電した三角形の数(端子を角に使ったものは除く)。
  - 消えるもの = 得点した三角形の辺と角の点、消えた点につながる線、回路をつないだ最後の線。
  - 点の飛び越え: 線から `BLOCK_RADIUS`(16)以内に別の点があると引けない。
- 手番の進行は `lib/gameEngine.ts`。判定するのは線を引いた人の回路だけ。相手の線でつながった回路は、その人の番のはじめに通電する。
- 三角形のない回路(自分・相手どちらでも)をつなぐ線は引けない(`checkMove`)。
- 終了: 手番の人が引ける線がなくなったとき。線が残るか得点して点が減るかのどちらかなので、必ず終わる。

## 構成

Next.js + Socket.IO のカスタムサーバー(`server.ts`)。部屋はメモリ上に保持。Dockerfile あり(Railway でそのまま動く)。
